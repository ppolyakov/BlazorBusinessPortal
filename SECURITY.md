# Security Policy

BusinessPortal is a portfolio demonstration project, not a hosted service with a security response team.

If you discover a vulnerability, use the repository host's private vulnerability reporting feature when available. Otherwise, open a minimal issue that describes impact and reproduction without publishing secrets, credentials, personal data, or an immediately exploitable payload.

Security-sensitive areas include organization isolation, role enforcement, approval concurrency, Identity endpoints, spreadsheet formula injection, audit redaction, and dependency vulnerabilities.

Do not use the demonstration credentials or configuration conventions for a public deployment without a dedicated production security review.
