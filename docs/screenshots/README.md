# Screenshot Capture Plan

Run the seeded demo at 1440×1000 or larger. Hide browser bookmarks and personal profile data.

1. **Dashboard** — route `/`; sign in as `manager@northstar.demo`; capture all four KPIs, hours chart, and recent activity.
2. **Projects with filters** — route `/projects`; filter status to `Active`; include the budget utilization bars.
3. **Project work** — use the `Tasks` action for `ARC-OPS`; route becomes `/work-items?project=<id>`; include mixed priorities and one overdue item.
4. **Approval workflow** — route `/approvals`; before capture, submit one Employee draft so the queue contains a realistic entry; show the rejection-feedback panel without submitting it.
5. **Reports and Excel** — route `/reports`; choose the previous two months and an active project; include KPI cards, chart, detail rows, and the Export Excel button.

Use the same seeded state for all images. Do not include environment variables, passwords, browser developer tools, or claims about real customers.
