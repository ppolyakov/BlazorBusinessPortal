# Upwork Portfolio Copy

## Title

Blazor Business Management Portal | .NET & PostgreSQL

## Role

Full Stack .NET Developer — architecture, backend, database and Blazor UI

## Description

A production-style portfolio project built with ASP.NET Core, Blazor, EF Core, and PostgreSQL. It includes organization-based data isolation, role-based access, clients, projects, work items, time tracking, approval workflows, reporting, Excel export, audit history, Docker, and automated tests. The project demonstrates how I design maintainable full-stack .NET applications with real business rules and data-heavy interfaces.

- **35–48s:** Sign out, sign in as Employee, create a draft time entry, and submit it.
- **48–63s:** Return as Manager, open Approvals, inspect the entry, and approve it.
- **63–78s:** Open Reports, apply a date/project filter, and export the current result to Excel.
